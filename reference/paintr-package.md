# paintr: Create Graphics of 'R' Data Structures

Draw teaching diagrams of the contents of common 'R' data structures.

## Details

paintr draws five structures (vectors, matrices, data frames, lists, and
arrays) with two backends, base graphics through the `paint_*()`
functions and 'ggplot2' through the `gpaint_*()` functions. The label
under each cell is the expression you would type to reach that cell, so
every picture doubles as a lesson in how to subset and index the object
it draws.
